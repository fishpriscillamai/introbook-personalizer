# 标准源整理与页面保护

## 建立品牌基准

每份源文件标明品牌、版本和语言。不要只换 Logo 就将明道云转换为 Nocoly；使用各自标准口径。保留源文件，以本地相对资源归集成 HTML，版本不可覆盖。旧资料不自动成为最新基准。

用户指定官方网页时，保存原始 HTML、实际引用的 CSS/JS/图片/字体及资源清单，记录来源 URL、抓取时间与逐文件指纹，断网核验资源完整性。抓取日期表示本地快照日期，不代表网页发布日期。网页包属于可用标准源；是否存在 PPTX 只能按实际公开下载入口判断，禁止猜测隐藏源文件路径。未经分类/导航适配/登记，下载副本还不是已启用的 Skill 模板。

收到源文件后先逐页渲染、读取文字和图形，再由 AI 提出页面策略并直接执行。不要只依赖文字关键词判断一张图是否属于技术架构；架构、安全认证、统计和其他事实必须保留。未知页整页锁定。

输入 HTML 使用显式闭合标签。页面是 `section`，可带 `data-slide` 或 `class="slide"`，也可直接标 `data-page-id`。双语页面放在带 `data-locale-deck="zh|en"` 的容器中。工具自动补稳定 page ID 和叶级文字/图片 slot ID。数字页码不是稳定 ID。

源导航需在归档前适配动态页数：基于 `[data-page-id]` 枚举当前页；目录标题从当前页文字提取；增加/删除案例后自动重算。语言控制须只列出实际存在的语言。不要把基于旧页数的固定目录原封不动带入可增删模板。整理后的 HTML 先完成视觉和导航检查，再登记为基准。标准产品与公司页的图文位置、比例、字体和品牌视觉保持原样。案例/方案可作局部布局扩展以清楚呈现客户证据与伙伴归属，扩展须受控记录、可重建验证，并实际检查排版。

## 页面模式

| mode | 用途 | 修改范围 |
|---|---|---|
| locked | 技术架构、价值八方式、事实、未知内容 | 整页保留，只有工具生成的页码/无障碍页码可更新 |
| partial | 部分业务文案可调 | 仅 editable 明确列出的文字槽位 |
| rewrite | 定位、价值、能力的业务化解释 | 仅 editable 文字槽位，保留事实和图形 |
| replaceable | 客户案例或伙伴方案 | 可删除或克隆，所有可变内容配套替换，必须关联已核验来源 |

先 `inspect` 输出结构清单，再结合渲染图生成 policy.json：

```json
{"pages":[{"id":"p-zh-2","mode":"partial","reason":"定位说明可改，产品模块与技术事实保留","editable":["s-2"]}]}
```

未写的页面由保守规则分类：架构强制锁定，产品数字/认证/技术/部署等槽位不可解锁，其他未知页保留。自动规则是防错下限，不替代视觉和业务判断；AI 必须将图中的事实、Logo、安全矩阵等留在锁定范围。整页图片里的内容不能当作可编辑文字。

案例策略的 editable 应覆盖每个客户特定内容。`decorative` 只列出可沿用的纯装饰图片槽位，禁止将客户 Logo/截图标为装饰。方案页标题为“伙伴解决方案：方案名称”，公开伙伴公司全称在主标题下新增独立副标题，保留流程图等原有小标题，不当作客户成果。当前流程型模板支持独立 partnerCompany 字段，新增局部页头元素；不改共享 CSS 或锁定页。无匹配版式时调整案例/方案局部布局或换模板，不通过删栏目、占用小标题或随意缩字塞入。

登记命令会先内嵌本地资源，再把标准 HTML 与 policy 指纹写入版本 manifest。模板改动需注册新版本；现有工作副本保留旧版本。生成结果通过从标准副本和修改记录重建后的全文比较保护，包含共享样式、脚本和图片字节。

## 资源边界

仅支持相对路径的本地图片和字体、经典本地 JS 与已展平的 CSS。禁止外链资源、iframe、视频/音频、async/module 脚本、CSS @import 和未整理的 srcset；遇到时先整理源文件，不静默丢弃。SVG 必须自包含且无活动脚本。

href 可以指向公开网页，点击后联网；阅读手册本身不得发出网络请求。资源最终内嵌为 data URI，不能把内部下载 URL、凭据、源文件绝对路径放入成品。

2026-10-19 官方网页的 `adapt-web` 策略：每品牌每语言 P1/P3/P4/P5 仅开放业务解释槽位；2026-10-23 起 P12“HAP 创造价值的八种方式”整页锁定，P14–P23 为成套案例模板，其余整页保留。数字、安全/权限、技术自主、部署边界、伙伴归属与品牌内容保留。架构页通过显式页面身份强制锁定；案例正文中提及 IT 架构不等同于架构图。

步骤 01–04 与通用栏目名属于固定版式，不需要伪造案例证据替换；客户名、引语、成果等仍须全部替换。目录取当前案例标题槽位，无障碍标题通过引用同一槽位更新。案例或方案无法满足整页版式的信息要求时，保留标准案例并记录缺口。
